# Iris Flower Species Classification

## Problem Statement
Build a Machine Learning classification system to automatically predict the species of an Iris flower based on its physical measurements.

## Dataset
- 150 samples, 3 species (50 each)
- Features: SepalLengthCm, SepalWidthCm, PetalLengthCm, PetalWidthCm
- Target: Iris-setosa, Iris-versicolor, Iris-virginica

## Models Used
| Model | Accuracy |
|-------|----------|
| Logistic Regression | 96.67% |
| KNN | 95.33% |
| Naive Bayes | 95.33% |

## Best Model
**Logistic Regression** with 96.67% accuracy

## Note
As per assignment: trained on 50% of data, tested on 100%
